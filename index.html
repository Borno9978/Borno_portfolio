My Design Process

  1. Research & Discovery: Understanding user pain points, target audience, and project goals.
  2. Wireframing & Sketching: Creating low-fidelity structural layouts using Balsamiq and hand sketches.
  3. UI Design & Prototyping: Crafting modern glassmorphism interfaces and interactive flows in Figma.
  4. Frontend Implementation & Testing: Developing responsive pages with HTML, CSS, JavaScript and testing across browsers.
